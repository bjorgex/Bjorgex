Master's student in Mechatronics and Automation at NTNU Ålesund (Robotics and Intelligent Systems, 2026 to 2028), moving from IT operations into engineering. Since 2021 I have run IT operations and built internal tools at Godt Brød Norge, a 30-location bakery chain.

## What I'm working on

- **Robotics and control (NTNU):** Kalman filters (EKF, UKF, particle filter), PID control of a DC motor, robot kinematics in C++ with Eigen, and the controller board for a 6-DOF ball-balancing platform (KiCad, Teensy 4.0).
- **IT automation at Godt Brød:** employee lifecycle from HR to Entra ID and the systems staff use, and a portal that checks HR records against every system that grants access.
- **Topptur (side project):** a ski-touring planner for Norway that puts terrain, avalanche, snow, sun and weather on one map, built on open data from Kartverket, NVE/Varsom, MET and seNorge. More to come. 🏔️
- **AI-assisted development:** building a pipeline where feedback from end users goes straight to AI agents that write and review the change, so it is ready to ship after a human review, with no prompting in between.

Most of my code (master's coursework and work tools for Godt Brød) lives in private repos.
